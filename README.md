## ⚙️ 配置指南

下载好压缩包直接打开 `DGHub` 进入后打开 `插件中心` 后点击 `外部插件` `导入zip包`

启动游戏后再启动插件，否则无法使用

你可以通过进入配置调整：
- `基址（叶六进制）`：定位变数
- `偏移链（逗号分隔）`：后置定位

---

## 🙋 常见问题

**Q：无法开启该插件**  
A：请下载补全pymem。

**Q：如何卸载？**  
A：直接从DGHub插件中心外置插件，点垃圾桶图标即可删除。
